# Content Repurposing Workflow

One long-form piece in, channel-ready drafts out.

## The problem

A blog post, podcast or webinar takes days to produce and then gets shared once. Rewriting it by hand for LinkedIn and a newsletter takes almost as long as the original. When the author is a busy executive, the rewriting usually just doesn't happen.

## What this does

One prompt takes a source piece and writes a first draft for each channel in that channel's native format. It can also take a voice guide from the brand-voice-prompt-kit so the drafts sound like the person who signs them.

## How to use it

1. Open `prompts/01-repurpose.md` and fill in the bracketed fields.
2. Paste it into the AI tool you use.
3. Edit every draft before it goes out. The prompt gets you to a first draft, not a final one.
